# Luna Beauty — կոսմետիկայի օնլայն խանութ

Պարզ frontend նախագիծ՝ HTML, CSS և JavaScript-ով։

## Ֆայլեր
- `index.html` — էջի կառուցվածքը
- `style.css` — դիզայնը և responsive դասավորությունը
- `script.js` — ապրանքների ցուցադրումը, որոնումը, ֆիլտրերը և զամբյուղը

## Ինչպես բացել VS Code-ում
1. ZIP-ը բացիր (Extract All)։
2. VS Code-ում ընտրիր **File → Open Folder** և բացիր `luna-beauty-store` թղթապանակը։
3. Բացիր `index.html` ֆայլը։ Կարող ես օգտագործել Live Server ընդլայնումը կամ բացել ֆայլը browser-ում։

## Ինչպես հրապարակել GitHub Pages-ում
1. GitHub-ում ստեղծիր նոր public repository, օրինակ՝ `luna-beauty-store`։
2. Upload files-ով վերբեռնիր `index.html`, `style.css`, `script.js` (կարող ես նաև README.md-ը)՝ repository-ի հիմնական մակարդակում։
3. Սեղմիր **Commit changes**։
4. Բացիր **Settings → Pages**։
5. Source-ում ընտրիր **Deploy from a branch**։
6. Branch-ում ընտրիր այն branch-ը, որտեղ ֆայլերդ են՝ սովորաբար `main` կամ `master`, իսկ folder-ը՝ `/(root)`։ Սեղմիր **Save**։
7. Սպասիր մի քանի րոպե և Settings → Pages էջում բացիր հրապարակված կայքի հղումը։

## WhatsApp պատվեր
`script.js`-ում փոխիր
`const WHATSAPP_NUMBER = "374XXXXXXXX";`
քո WhatsApp համարով՝ երկրի կոդով և առանց `+`, բացատների կամ գծիկների։ Օրինակ՝ Հայաստանի համար սկսվում է `374`-ով։ Մինչև համար չավելացնես, WhatsApp պատվերի կոճակը միայն հիշեցում կցուցադրի։

## Կարևոր
Սա frontend ցուցադրական խանութ է։ Ապրանքների գները և նկարները օրինակային են, էլ. փոստի բաժինը տվյալներ չի պահպանում, իսկ վճարումներ/իրական պատվերների պահպանում դեռ չկա։
